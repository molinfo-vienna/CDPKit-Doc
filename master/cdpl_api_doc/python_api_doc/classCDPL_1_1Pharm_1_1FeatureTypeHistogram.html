Detailed Description

Data type for the storage of feature type histograms of pharmacophores.

FeatureTypeHistogram is a unique associative map where the keys specify the feature type (defined in namespace Pharm.FeatureType) of the pharmacophore features and the mapped integer values correspond to the feature type frequencies.
